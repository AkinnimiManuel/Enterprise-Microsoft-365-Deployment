# 🔐 Identity Management

This section documents the complete identity management implementation for the **Enterprise Microsoft 365 Deployment** project. It covers the planning, deployment, governance, and validation of Microsoft Entra ID identities for **Probryx Technologies Ltd.**

## 📖 Overview

The Identity Management phase focuses on establishing a secure and scalable identity platform by implementing enterprise best practices for:

- User provisioning
- Administrative role delegation
- Role-Based Access Control (RBAC)
- Authentication methods
- Multi-Factor Authentication (MFA)
- Self-Service Password Reset (SSPR)
- Security Groups
- Microsoft 365 Groups
- Identity lifecycle management (Joiner, Mover, Leaver)
